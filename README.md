# Faysal Talukder — Personal Hub

Static, no-build website. Open `index.html` directly or deploy the folder to GitHub Pages-style hosting.

## Structure
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `case-studies/index.html` — Halal Food case study
- `blog/index.html` — Info Orbit index
- `blog/*.html` — 6 complete demo posts
- `resources.html` — resources
- `contact.html` — contact form
- `css/style.css` — all styling
- `js/main.js` — navigation, blog filtering, contact mailto behavior
- `images/` — predictable image placeholders
- `documents/` — demo downloadable resources
