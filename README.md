# আমার ব্লগ সাইট — সেটআপ নির্দেশনা

## ধাপ ১: GitHub রিপোজিটরি তৈরি করা

1. GitHub-এ লগইন করো
2. উপরে ডানদিকে **+** আইকনে ক্লিক করে **New repository** সিলেক্ট করো
3. রিপোজিটরির নাম দাও: `username.github.io`
   - এখানে `username` এর জায়গায় তোমার আসল GitHub ইউজারনেম বসাবে (হুবহু)
   - উদাহরণ: তোমার ইউজারনেম যদি `faisal123` হয়, রিপো নাম হবে `faisal123.github.io`
4. **Public** সিলেক্ট করা আছে কিনা নিশ্চিত করো
5. **Create repository** ক্লিক করো

## ধাপ ২: ফাইলগুলো আপলোড করা

1. নতুন তৈরি হওয়া রিপোজিটরির পেজে যাও
2. **"uploading an existing file"** লিংকে ক্লিক করো (অথবা **Add file > Upload files**)
3. আমি যে ফাইল/ফোল্ডারগুলো দিয়েছি — সবগুলো (পুরো ফোল্ডারসহ) ড্র্যাগ করে ওই আপলোড বক্সে ফেলো
   - **গুরুত্বপূর্ণ**: `_layouts`, `_posts`, `assets` ফোল্ডারসহ সব ফাইল একসাথে দিতে হবে, ফোল্ডার স্ট্রাকচার যেন ঠিক থাকে
4. নিচে "Commit changes" বাটনে ক্লিক করো

## ধাপ ৩: GitHub Pages চালু করা

1. রিপোজিটরির উপরে **Settings** ট্যাবে যাও
2. বামপাশের মেনু থেকে **Pages** এ ক্লিক করো
3. **Source** এর নিচে **Deploy from a branch** সিলেক্ট করো
4. Branch হিসেবে **main** এবং ফোল্ডার **/ (root)** সিলেক্ট করে **Save** করো
5. ১-২ মিনিট অপেক্ষা করো — তারপর ওই পেজেই একটা লিংক দেখাবে, যেমন:
   `https://username.github.io`
   এটাই তোমার লাইভ ওয়েবসাইট!

## ধাপ ৪: `_config.yml` ফাইলে সাইটের ঠিকানা বসানো

আপলোডের পর GitHub-এ গিয়ে `_config.yml` ফাইলটা এডিট করো (পেন্সিল আইকনে ক্লিক করে) এবং এই দুই লাইন পরিবর্তন করো:

```
baseurl: ""
url: "https://username.github.io"
```

(`username` এর জায়গায় তোমার GitHub ইউজারনেম বসাও, `baseurl` খালি রাখো কারণ এটা মূল ইউজারনেম সাইট)

## ধাপ ৫: নতুন পোস্ট লেখা

1. `_posts` ফোল্ডারে যাও
2. **Add file > Create new file** ক্লিক করো
3. ফাইলের নাম দিতে হবে এই নিয়মে: `YYYY-MM-DD-post-er-nam.md`
   - উদাহরণ: `2026-09-10-amar-notun-post.md`
4. উপরে এই ফরম্যাট বসাও, তারপর নিচে লেখা লিখো:

```
---
layout: post
title: "তোমার পোস্টের শিরোনাম"
date: 2026-09-10 10:00:00 +0600
tags: [ট্যাগ১, ট্যাগ২]
description: "এক লাইনে পোস্টের সংক্ষিপ্ত বিবরণ (SEO-র জন্য গুরুত্বপূর্ণ)"
---

এখানে তোমার পোস্টের মূল লেখা শুরু হবে।

## সাব-হেডিং

আরও লেখা...
```

5. নিচে **Commit changes** করলেই ১-২ মিনিটের মধ্যে পোস্ট লাইভ হয়ে যাবে

## পোস্ট ডিলিট করা

`_posts` ফোল্ডারে গিয়ে যে পোস্ট ডিলিট করতে চাও সেটায় ক্লিক করো, তারপর ডানদিকে ট্র্যাশ (🗑️) আইকনে ক্লিক করে **Commit changes** করো।

## গুরুত্বপূর্ণ টিপস

- ফাইলের নামে বাংলা অক্ষর না দেওয়াই ভালো (ইংরেজি/রোমান হরফে দাও), তবে টাইটেল ও লেখা বাংলায় দিতে কোনো সমস্যা নেই
- প্রতিটা পরিবর্তনের পর সাইট আপডেট হতে ১-৩ মিনিট সময় লাগতে পারে
- সাইট আপডেট হচ্ছে কিনা দেখতে রিপোর **Actions** ট্যাবে যাও (সবুজ টিক মানে সফল)
